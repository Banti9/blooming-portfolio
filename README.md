# Blooming Into Technology — KM Banti Chauhan

A floral, responsive React portfolio starter with falling petals, a welcome screen, animated sections, and bloom-inspired interactions.

## Run locally

1. Install Node.js (LTS).
2. Extract this project folder.
3. Open a terminal in the folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Personalize before publishing

Search in `src/main.jsx` and replace:
- `your.email@example.com` with your real email.
- GitHub and LinkedIn placeholder URLs with your profiles.
- Project GitHub links with the actual repositories.
- Edit project descriptions and skills so they accurately reflect your work.

## Build for deployment

```bash
npm run build
```

The production files are created in `dist/`. You can deploy the project to Vercel by importing its GitHub repository.

## Notes
- This is a starter portfolio, not a published website.
- Do not add made-up coding statistics or achievements.
- The decorative petal animation respects reduced-motion accessibility settings.
